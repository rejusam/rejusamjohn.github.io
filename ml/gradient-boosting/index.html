Gradient boosting

Add small trees one at a time, each fitted to what the model still gets wrong.

About 12 minutes · No maths needed; the maths is there if you want it

Overview

In bagging and random forests, many trees are grown side by side and their answers averaged. Boosting grows trees one after another instead. Each new tree is tiny, and its job is to fix what the trees before it still get wrong.

We use the wave data from Overfitting and regularisation, with more points. We start with one tiny tree, look at what it misses, add a second, then add hundreds and watch training and test error. We finish with the reason for the word "gradient".

The points are made up. See "About the data" at the end.

You'll learn

  • how boosting builds a model round by round, each small tree fitted to the residuals of the model so far
  • why training error keeps falling while test error turns back up, and how the learning rate η and the number of rounds M work together
  • why the residuals are a gradient, which puts the "gradient" in gradient boosting

    Fit a second stump, not to y but to the residuals. Then add it to the model.

    Adding it gives the new model, F₂ = F₁ + h₂ (η = 1 here). On the left, the old model is dashed and the new one solid. Training MSE falls from to .

    That is the whole method: fit a stump to the residuals, add it, work out the new residuals, and repeat. Each repeat is called a round.

    In practice you add only a fraction of each stump: η times it, where η (eta) is a small number such as 0.1. η is the learning rate. It plays the same role as the learning rate in gradient descent: it sets the size of each step. In these first three steps η = 1, so each change is easy to see. From the next step on, η = 0.1 (step 5 lets you change it).

  6. Why "gradient"?

    The residuals are not just leftovers. They point downhill on the loss, one number per training point.

    Score the prediction F at one training point with the loss ½(yᵢ − F)², half the squared error. If F is too low, raising it lowers the loss; if F is too high, lowering it does. The slope of this loss with respect to F is −(yᵢ − F). So the downhill direction, the negative gradient, is yᵢ − F: exactly the residual.

    The plot shows the model after 10 rounds with η = 0.1. Each stick on the right is one point's residual: how far, and which way, that point's loss says its prediction should move. The next stump, dashed, splits at x = .

    So each round is like a step of gradient descent, where what moves is the model's predictions rather than a weight. This is a simplification. The negative gradient is only known at the 40 training points, so boosting approximates it with a stump, which also says what to do between and beyond them, and then steps η times that stump.

    Change the loss and the recipe still works: fit each stump to the new loss's negative gradient instead of the residual. That is how gradient boosting does classification, using the log-loss from logistic regression.

    The maths

    With the loss L(y,F)=12(y−F)2L(y, F) = \tfrac{1}{2}(y - F)^2L(y,F)=21​(y−F)2,

Quick check

What does each new stump try to fit?

Only the first stump is fitted to y (after taking off the mean). Fitting y again would give the same stump every round.

Right. Each stump is fitted to rᵢ = yᵢ − F(xᵢ), what the model so far still gets wrong. For squared error, that is also the negative gradient of the loss.

Every training point is used in every round. Points the model already fits well have small residuals, so they pull the next stump less.

The test points are never used for fitting. They are kept aside to check the model on points it has not seen.

Why might you stop early?

With least-squares stumps and 0 < η < 2, the training error never rises. That is exactly why it cannot tell you when to stop.

Right. With η = 0.1, the test MSE (on held-out data) is lowest at M = () and is by M = 300, while the training MSE keeps falling. The later stumps fit noise.

There is always a split to make: 40 points have 39 gaps between them, and the residuals change every round. The rounds never run out.

η and M are separate settings. Stopping early changes M, not η. A smaller η usually needs more rounds, not fewer.

Lesson complete

  • Boosting builds a model as a sum: start from the mean, then add η times a small tree, round after round.
  • Each tree is fitted to the residuals of the model so far. For squared error, the residuals are the negative gradient of the loss.
  • With least-squares stumps and 0 < η < 2 the training error never rises, but the test error has a lowest point, so the number of rounds M is chosen on held-out data.
  • A smaller η takes smaller steps and needs more rounds.

Common misconceptions

  • "More rounds is always better." The training error keeps falling, but the test error turns back up.
  • "Boosting averages independent trees, like a random forest." Its trees are built one after another, and each depends on the ones before it.
  • "A smaller η is always better." It needs many more rounds for about the same result: here the best M is at η = 0.05 against at η = 0.1, with the same lowest test MSE, , to three decimals.

For each point, x is drawn uniformly between −1 and 1, then y = sin(πx) + 0.25 z, where z is a draw from a normal distribution with mean 0 and SD 1, made with mulberry32.
